# Curling Game SDLC Lab

This repository is a hands-on lab for exploring the software development lifecycle (SDLC) from end to end by creating a browser-based curling game. Participants follow the included workshop instructions to move through planning, implementation, testing, review, and final delivery.

## What this lab covers

The goal is to experience the full SDLC in a simple, practical example:

- Define user requirements and scope
- Design a lightweight technical architecture
- Break the work into backlog tasks
- Build the game incrementally in code
- Validate behavior with automated tests
- Debug, review, and improve the solution
- Document onboarding steps and prepare a demonstration

This repo uses a simplified curling game as the example product, with a local two-player browser game built using HTML5 canvas, JavaScript, CSS, Vite, and Vitest.

## Lab instructions

The full set of step-by-step instructions for the lab can be found in the Markdown file:

- [GitHub Copilot_ Curling Game SDLC Prompt Playbook.md](GitHub%20Copilot_%20Curling%20Game%20SDLC%20Prompt%20Playbook.md)

Follow the numbered stages in that file one at a time in GitHub Copilot Chat. Each stage builds on the previous one so the lab reflects a realistic SDLC workflow from requirements through delivery.

## Getting started

1. Open the repository in VS Code.
2. Open the playbook file linked above.
3. Follow the prompts in order, using GitHub Copilot in Plan or Agent mode as directed.
4. Run the game locally as the lab instructs.

Typical local commands:

```bash
npm install
npm run dev
npm run test
npm run build
```

If the project scripts differ, use the commands listed in `package.json`.

## Learning outcome

By the end of the lab, users will have built and validated a working curling game while exploring how the SDLC connects requirements, design, coding, testing, and documentation into a complete software project.
